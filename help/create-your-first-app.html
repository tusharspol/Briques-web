Getting started

Create your first tracker

← All help articles

There are two ways to create a tracker. Both start from the home screen — tap New.

Describe it with AI

  1. Tap New and type a short description of what you want — for example, "a tracker for my freelance invoices with client, amount, and paid status."
  2. Briques interprets the idea, plans the screens and data, and generates a working tracker. This spends AI credits (see how credits work).
  3. Review what it made. Keep editing by hand, or ask for changes in plain language.

Set it up yourself

  1. Create a tracker with just a name.
  2. From the tracker's home, add Tables to hold your data, then Pages to show and edit it.
  3. Use the page builder to place text, lists, buttons, and forms.

When it looks right, make it live to start using it.

Tip: Start small. A first tracker with one table and two screens is far easier to get right than a sprawling one — and you can always add to it later.
